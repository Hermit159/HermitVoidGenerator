# Hermit's Void Generator

Hermit的虚空生成器 —— **Probably Stolen** 的原生 mod（走游戏自带 ModLoader，不依赖 BepInEx）。作者 **Hermit**，版本 **1.0.4**。

游戏内显示的名字是中文的「Hermit的虚空生成器」；工程、程序集、目录、ID 一律用英文 `HermitVoidGenerator`。

## 功能

- **基础修改** — 不用改存档就能调的账目与店铺参数，一页全在里面：现金、房租（金额 + 剩余天数）、贷款（金额 + 剩余天数）、店铺吸引力与投影加成、定价加成（零售加价 + 违禁品低/中/高/极高四档）、**六阵营声望**、**恩惠**、**配给券余额**，以及**伤势**。伤势用下拉选——游戏里没有具名等级，只有 0..10 的 `woundState` 和阈值 5（>5 算重伤），所以给 7 个有意义的档位：无伤(0) / 轻伤·轻微(2) / 轻伤·中等(4) / 轻伤·临界(5) / 重伤·轻微(6) / 重伤·严重(8) / 重伤·濒危(10)，另配「伤势稳定」开关（稳定夜里 −4 愈合，不稳定可能 +1 恶化）。每行右边一个「写入」，改完立刻生效；「刷新数值」重新读当前值。声望改的是 `StoreReputation.SetReputation`（范围 ±200，写进去游戏自己调 `CheckReputation` 夹范围并重算该阵营所有 perk 的解锁状态），旁边实时显示游戏自己的档位名（中立 / 略有耳闻 / … / 声威赫赫，负档到黑名单）；不走 `ModReputation`——那个会叠天赋、黑市、治安部、难度倍率一堆修正，还会顺手改 `wildFavor` 弹通知。现金直接赋 `PlayerStore.playerCash`，不走 `ModCash`（那个会播收银机音，界面没开时会空引用）。恩惠就是 `PlayerStore.wildFavor`（UI 里的「王尔德的恩惠」）；配给券余额就是食堂记账 `CommissaryData.redeemedCredit`。

- **物品添加** — 浏览/搜索全物品目录，左键选中后右边填参数：数量、单价、落点（店内库存 / 前台 / 展示柜 / 后仓 / 自动安置），以及这件物品的**规格**——液体成分逐种填毫升、水纯度、药物主成分与制品纯度、金属锭纯度、耐久、可升级机器的等级；还有**配给券**（面值、真伪）与全量**词条**修改。生成完自动造下一件同款草稿并照抄规格，方便连着出。

- **物品编辑** — 左侧列出前台柜台 / 后柜台 / 展示柜上的物品（可勾选含店内库存），点一件就能改；也可以用「点选物品」去店里直接指。改的是数量、单价、基础价、迟价（四个小格子两两一行；表单区根本不套滚动容器，物品名和 id 那行长到三四行也照实撑开，给每段文字量完实际行高再让父级重排——「应用修改 / 重新载入 / 复制一件」永远排在表单最下面看得见，下面的规格/词条面板自动贴上来）+ 同一套规格/耐久面板。名称、描述这类只影响显示的东西不在这里。

- **界面语言** — 物品列表、分类下拉、词条名字全部中文。游戏本地化表里有条目的用游戏译名；只有英文的（源码里硬编码那批）走 `ItemNames` 的手工表 + 词素表兜底。右栏文字按面板宽度自动换行、必要时缩字号，不会挤破边框。词条悬停显示原始 tag + 这条词条干什么、改了会怎样、可填范围。选中格子是图标本身满亮度 + 后面衬一层金色光晕，没选中的图标压到 55% 透明度，图片永远看得清。**分类按 wiki 百科的物品页来分，分两层**：上面一个下拉是 17 个大分类（食物与水 / 日用品 / 烟酒类 / 医疗品 / 材料 / 工程 / 工具 / 农业 / 化学 / 武器装备 / 物资箱 / 艺术品 / 奢侈品 / 机器 / 文档 / 可鉴定物品 / 其它），下面一个下拉是选中大分类后里面的小分类（共 39 个在用的小分类，顺序和分组都照 wiki 表格）。**一件物品可以同时挂在几个小分类下**。wiki 没收录的物品统一落在「游戏目录」大类里。两个下拉都会随搜索瘦身：没有匹配物品的大类 / 小类直接消失，留下来的名字后面用「(N)」标出命中几件。

- **词条面板（三页共有）** — 规格下面自动列出这件物品身上带着的每一条 tag，按 能源 / 使用次数 / 武器 / 护甲 / 食物 / 生物 / 存储 / 归属与交易 / 其它 分组，中文名 + 当前值 + 写入。能源类包括电池的「剩余储电 / 储电上限 / 供能带宽 / 自充速率」、机器的「当前电量 / 电量上限 / 充电速率 / 功耗」、反应堆完整度与升级数；布尔词条是开关，其余是输入框。**801 条词条全部有中文名**，万一两条撞名，鼠标悬停能看到原始 tag。分类走 wiki 分类表 `src/HermitVoidGenerator/WikiCategories.g.cs`（17 个大分类 × 42 个小分类，365 个 id、403 条分类关系）。

热键 **Insert** 开关面板（输入框聚焦时不会误触）。

## 目录

- `src/HermitVoidGenerator/` — C# 源码（net472 类库）
- `manifest.xml` — 游戏读取的 mod 清单
- `HermitVoidGenerator.dll` — 编译好的 mod 本体（直接可用）

## 装进游戏

把 `HermitVoidGenerator.dll` 和 `manifest.xml` 一起放进：

```
<游戏目录>\Mods\HermitVoidGenerator\
```

## 首次启用（必须）

游戏只加载「已启用」的 mod，启用的同时会做信任扫描并记录指纹：

1. 启动游戏，进 **Mods** 列表
2. 找到「Hermit的虚空生成器」，点启用并批准（本地来源会提示未信任，批准即可）
3. 按提示 **重启游戏**（ModLoader 只在启动时扫描文件夹）
4. 进店里按 **Insert**

改了 dll 之后不用重新批准：指纹变了信任状态会变成 `Updated`，而 `ModLoader` 对 `Updated` 是直接放行并自动刷新记录的（只有新增能力声明才会变成 `Changed` 被拦）。

## 自己编译（可选）

需要 .NET SDK，以及游戏的 `Probably Stolen_Data\Managed` 目录提供引用程序集：

```
dotnet build src/HermitVoidGenerator/HermitVoidGenerator.csproj -c Release ^
  -p:GameManagedDir="<游戏目录>\Probably Stolen_Data\Managed" -o out
```
