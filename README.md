# Hermit's Void Generator

Hermit的虚空生成器 —— **Probably Stolen** 的原生 mod。作者 **Hermit**，版本 **1.0.6**。

## 功能

- **基础修改** — 一页改齐游戏里那些不好调的账目与店铺参数：现金、房租（金额 + 剩余天数）、贷款（金额 + 剩余天数）、店铺吸引力与投影加成、定价加成（零售加价 + 违禁品低/中/高/极高四档）、六阵营声望、恩惠、配给券余额，以及伤势（7 档下拉 + 「伤势稳定」开关，控制夜里愈合还是恶化）。每行一个「写入」，改完立刻生效，旁边「刷新数值」随时读当前值。

- **事件触发** — 「基础修改」左卡最下面一块。下拉里是游戏本体的全部事件（常规 / 特殊 / 派系行动 / 例行共四组、40 个，名字走游戏本地化表，切语言跟着变）；选中后下面那块文字立刻写出这个事件的简介和价格影响——哪类货涨多少、哪类跌多少，永久事件、会触发全站封锁的也各标一行。填好持续天数点「触发」，事件当场生效并写进店里的日历，点开日历就能看见它占哪几天；底下那行「日历上正在进行」实时列出当前事件和剩余天数。天数不是写死的：游戏的 `duration` 只是默认值，真正生效的字段可写，留空用默认、超过范围自动收口；唯一例外是永久事件，填了没用，面板会写明。

- **物品添加** — 浏览/搜索全物品目录，选中后填参数生成：数量、单价、落点（店内库存 / 前台 / 展示柜 / 后仓 / 自动安置），以及这件物品的规格——液体成分逐种填毫升、水纯度、药物主成分与制品纯度、金属锭纯度、种子基因、耐久、可升级机器的等级；配给券（面值、真伪）与全量词条也能指定。生成完自动造下一件同款草稿并照抄规格（连基因一起抄），方便连着出。格子上悬停先给英文 id，空一行接游戏原本给这件物品写的那段说明，有风味文本的再另起一段，挑东西不用靠名字猜。

- **物品编辑** — 左侧列出前台柜台 / 后柜台 / 展示柜上的物品（可勾选含店内库存），点一件就能改数量、单价、基础价、迟价，或用「点选物品」去店里直接指。规格、耐久、词条全在同一处改，可「复制一件」再调。顶上一条关键词搜索 + 大类 / 小类两级下拉，和物品添加同一套，件数按台面上现有的物品算，没命中的分类直接消失；点选到的物品要是被筛选挡住，筛选会自动清空，保证它在列表里露出来。

- **种子基因** — 选中的物品是种子才会出现的规格块：品种、原种 / 已变异、复杂度、基因热量；已有性状逐条填等级（填 0 就把这条去掉），未拥有性状可加，游戏不让加的标「（受限）」、按钮变「强加」，原因在悬停提示里；行尾「恢复原种」按品种先天表整条洗回去、「清空热量」把基因热量归零。性状名与效果说明走游戏自己的本地化表，写值走游戏的 SetTraitRank，所以已变异类型、营养果品系图标与单价会跟着一起刷新。

- **界面语言** — 物品列表、分类下拉、词条名字全部中文，词条悬停显示这条词条干什么、改了会怎样、可填范围。选中格子整格填黄铜、文字转深墨色，没选中的只留暗底衬。**分类按 wiki 百科的物品页分两层**：17 个大分类（食物与水 / 日用品 / 烟酒类 / 医疗品 / 材料 / 工程 / 工具 / 农业 / 化学 / 武器装备 / 物资箱 / 艺术品 / 奢侈品 / 机器 / 文档 / 可鉴定物品 / 其它），每个大类里再分小分类，一件物品可以同时挂在几个小分类下，wiki 没收录的物品统一落在「游戏目录」。分类下拉随搜索瘦身，名字后面「(N)」标出命中几件。

- **词条面板** — 三页共用，规格下面自动列出这件物品身上带着的每条词条，按能源 / 使用次数 / 武器 / 护甲 / 食物 / 生物 / 存储 / 归属与交易 / 其它 分组，中文名 + 当前值 + 写入。801 条词条全部有中文名，重名的鼠标悬停看原始 tag。

热键 **Insert** 开关面板（输入框聚焦时不会误触）。

## 目录

- `src/HermitVoidGenerator/` — C# 源码（net472 类库）
- `manifest.xml` — 游戏读取的 mod 清单
- `HermitVoidGenerator.dll` — 编译好的 mod 本体（直接可用）

## 装进游戏

把 `HermitVoidGenerator.dll` 和 `manifest.xml` 一起放进：

```
<游戏目录>\Mods\HermitVoidGenerator\
```

## 首次启用（必须）

游戏只加载「已启用」的 mod，启用的同时会做信任扫描并记录指纹：

1. 启动游戏，进 **Mods** 列表
2. 找到「Hermit的虚空生成器」，点启用并批准（本地来源会提示未信任，批准即可）
3. 按提示 **重启游戏**（ModLoader 只在启动时扫描文件夹）
4. 进店里按 **Insert**

改了 dll 之后不用重新批准：指纹变了信任状态会变成 `Updated`，`ModLoader` 对 `Updated` 直接放行并自动刷新记录（只有新增能力声明才会变成 `Changed` 被拦）。

## 自己编译（可选）

需要 .NET SDK，以及游戏的 `Probably Stolen_Data\Managed` 目录提供引用程序集：

```
dotnet build src/HermitVoidGenerator/HermitVoidGenerator.csproj -c Release ^
  -p:GameManagedDir="<游戏目录>\Probably Stolen_Data\Managed" -o out
```
