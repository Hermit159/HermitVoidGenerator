# Hermit's Void Generator

Hermit的虚空生成器 —— **Probably Stolen** 的原生 mod。作者 **Hermit**，版本 **1.0.7**。

## 功能

**基础修改** — 一页改齐账目和店铺参数。

- 现金、房租、贷款，填数就写
- 店铺吸引力、定价加成（违禁品低 / 中 / 高 / 极高四档分开）
- 六阵营声望，写进去游戏自己夹范围并重算 perk
- 恩惠、配给券余额
- 伤势 7 档下拉 + 「伤势稳定」开关

**事件触发** — 让店里立刻发生游戏本体的某个事件。

- 下拉是游戏本体全部 40 个事件，按常规 / 特殊 / 派系 / 例行分组
- 选中就写出简介、生效区域、默认天数和价格影响
- 填几天点「触发」，当场写进店里的日历
- 永久事件不进倒计时，填了没用，会标出来

**物品添加** — 凭空生成任意物品。

- 搜索全物品目录，选一件填数量、单价、落点
- 落点：店内库存 / 前台 / 展示柜 / 后仓 / 自动安置
- 规格：液体成分逐种填毫升、水纯度、药物成分、金属纯度、耐久、机器等级
- 生成完自动造下一件同款草稿，规格整套照抄
- 悬停看英文 id，接游戏写的原文描述

**物品编辑** — 改台面上现有的物品。

- 列出前台 / 后柜台 / 展示柜的物品，可勾选含店内库存
- 搜索框 + 标签下拉，件数按台面上现有的算
- 能改数量、单价、基础价、迟价，也能改规格 / 基因 / 词条
- 「点选物品」直接去店里指，指到的会自动清筛选
- 「复制一件」再造一件改

**词条面板** — 三页共有。

- 列出这件物品身上带的每一条标签，中文名 + 当前值 + 写入
- 按 能源 / 使用次数 / 武器 / 护甲 / 食物 / 生物 / 存储 / 归属与交易 / 其它 分组
- 801 条词条全部有中文名，悬浮看原始 tag 和这条干什么
- 悬停三行：原始 tag、怎么填、在游戏里干什么改了怎样

**种子基因** — 选中的是种子才出现。

- 品种、原种 / 已变异、复杂度、基因热量
- 已有性状逐条填等级，填 0 就去掉这条
- 未拥有性状能加，游戏不让的标「（受限）」，按钮变「强加」
- 行尾「恢复原种」按品种先天表洗回去，「清空热量」把热量归零

**分类与搜索**

- 分类只有一层，就是玩家鼠标挪到物品上看到的那串标签
- 一件物品几个标签就挂几个分类，厨刀在「武器 / 近战武器 / 日用品」下都能找到
- 标签是运行时给每件物品造探针读出来的，不是静态猜的
- 游戏根本不给标签的那批合成「无标签」分类，放在最后
- 搜索框连标签名一起搜，搜「违禁」捞出所有违禁品
- 分类下拉随搜索瘦身，名字后面「(N)」标出命中几件

**中文**

- 物品名、分类名、词条名全部中文
- 游戏本地化表有条目就用游戏译名，只有英文的走手工表兜底
- 悬停提示里的标签颜色照游戏：常规浅青，违禁品整行浅红

热键 **Insert** 开关面板（输入框聚焦时不会误触）。

## 目录

- `src/HermitVoidGenerator/` — C# 源码（net472 类库）
- `manifest.xml` — 游戏读取的 mod 清单
- `HermitVoidGenerator.dll` — 编译好的 mod 本体（直接可用）

## 装进游戏

把 `HermitVoidGenerator.dll` 和 `manifest.xml` 一起放进：

```
<游戏目录>\Mods\HermitVoidGenerator\
```

## 首次启用（必须）

游戏只加载「已启用」的 mod，启用的同时会做信任扫描并记录指纹：

1. 启动游戏，进 **Mods** 列表
2. 找到「Hermit的虚空生成器」，点启用并批准（本地来源会提示未信任，批准即可）
3. 按提示 **重启游戏**（ModLoader 只在启动时扫描文件夹）
4. 进店里按 **Insert**

改了 dll 之后不用重新批准：指纹变了信任状态会变成 `Updated`，`ModLoader` 对 `Updated` 直接放行并自动刷新记录（只有新增能力声明才会变成 `Changed` 被拦）。

## 自己编译（可选）

需要 .NET SDK，以及游戏的 `Probably Stolen_Data\Managed` 目录提供引用程序集：

```
dotnet build src/HermitVoidGenerator/HermitVoidGenerator.csproj -c Release ^
  -p:GameManagedDir="<游戏目录>\Probably Stolen_Data\Managed" -o out
```
